# 1. CrCl สูตร Cockcroft-Gault — ตัวนี้ตัวเดียวที่ใช้ปรับขนาดยา

```
CrCl (mL/min) = ((140 − อายุ) × น้ำหนัก kg) / (72 × sCr mg/dL)
ผู้หญิง คูณ 0.85
```

- ใช้ค่า sCr ตามที่กรอก **ไม่ปัดขึ้นเป็น 1** และไม่ปัดทศนิยมก่อนคิด
- น้ำหนักที่ใส่ในสูตรมาจากข้อ 2 ไม่ใช่น้ำหนักที่กรอกเสมอไป
- แสดงผลทศนิยม 1 ตำแหน่ง · ปัดตอนแสดงเท่านั้น ห้ามปัดค่ากลางทาง
- คิดได้เมื่อครบ 4 อย่าง — เพศ อายุ sCr น้ำหนัก · ส่วนสูงไม่บังคับ (ข้อ 2 กรณีที่ 5)

# 2. น้ำหนักที่ใช้คิด — IBW · Adjusted BW · ลำดับเลือก 5 กรณี

```
ส่วนสูงเป็นนิ้ว = ส่วนสูง cm / 2.54
ส่วนที่เกิน 60 นิ้ว = max(0, ส่วนสูงเป็นนิ้ว − 60)      ← เตี้ยกว่า 60 นิ้ว ไม่ให้ติดลบ
IBW (Devine Formula)  ชาย  = 50   + 2.3 × ส่วนที่เกิน 60 นิ้ว
                      หญิง = 45.5 + 2.3 × ส่วนที่เกิน 60 นิ้ว
Adjusted BW = IBW + 0.4 × (BW − IBW)
```

**เช็กตามลำดับนี้ ข้อแรกที่เข้าคือคำตอบ**

| ลำดับ | เงื่อนไข | ใช้น้ำหนัก | IBW กับ Adjusted BW |
|---|---|---|---|
| 1 | ส่วนสูง **ต่ำกว่า 152 cm** | Actual BW | ขึ้น **N/A** ไม่คิด CrCl ของสองแถวนี้ (อาจหลังค่อม IBW ใช้ไม่ได้) |
| 2 | BW **น้อยกว่า** IBW | Actual BW | คิดแสดงให้ดู |
| 3 | BW **มากกว่า** 1.2 × IBW | Adjusted BW | คิดแสดงให้ดู |
| 4 | นอกนั้น (รวม BW เท่ากับ 1.2 × IBW พอดี) | Ideal BW | คิดแสดงให้ดู |
| 5 | **ไม่กรอกส่วนสูง** แต่อย่างอื่นครบ | Actual BW | ยังคิดไม่ได้ · ขอให้กรอกส่วนสูง |

- 🔴 **"อ้วน" ในตารางนี้ตัดสินจาก BW เทียบ IBW ไม่ใช่จาก BMI** · BMI ใช้แค่ไล่ระดับสีของกรณีที่ 3 ในต้นฉบับ
- 🔴 ส่วนสูง 152 cm พอดี **ไม่นับว่าเตี้ย** (ต้นฉบับใช้ `< 152`)
- ตัวเลขทุกแถว (Actual · Ideal · Adjusted) แสดงให้เห็นทั้งหมด แต่มีแถวเดียวที่ถูกเลือก

# 3. ขอบเขตค่า · การสลับหน่วย

| ช่อง | ต่ำสุด–สูงสุด (หน่วยหลัก) | หน่วยรอง | แปลงเข้าสูตร |
|---|---|---|---|
| น้ำหนัก | 20–200 kg | 44–441 lb | lb ÷ 2.20462 |
| ส่วนสูง | 100–230 cm | 40–91 in | in × 2.54 |
| อายุ | 15–110 ปี | — | — |
| sCr | 0.1–30 mg/dL | 9–2652 μmol/L | μmol/L ÷ 88.4 |

- **ขอบรวมตัวเอง** — 20 ผ่าน 19.9 ไม่ผ่าน · 200 ผ่าน 200.1 ไม่ผ่าน
- **เกินขอบ = ข้อผิดสีแดงที่ช่องนั้น และไม่คิด CrCl เลย** (ระบบห้าม)
- **อายุ 15–17 กับ 93–110 = เตือนสีส้มแต่ยังคิด** (ระบบเตือน) เพราะ Cockcroft-Gault ถูกตรวจสอบไว้ช่วง 18–92 ปี
- **กดสลับหน่วย ค่าในช่องแปลงตามต้นฉบับ** — kg↔lb ปัดเป็นจำนวนเต็ม · cm→in ทศนิยม 1 · in→cm จำนวนเต็ม · mg/dL→μmol/L จำนวนเต็ม · μmol/L→mg/dL ทศนิยม 2
- ค่าที่ใช้คิดคือค่าในช่องหลังแปลง แปลงเข้าสูตรด้วยตัวคูณในตาราง **ไม่ปัดระหว่างทาง**

# 4. eGFR สูตร CKD-EPI 2021 · ระยะ CKD — แสดงผลเท่านั้น

```
r = sCr / κ          หญิง κ = 0.7  α = −0.241
                     ชาย  κ = 0.9  α = −0.302
eGFR = 142 × min(r, 1)^α × max(r, 1)^−1.200 × 0.9938^อายุ × 1.012 (เฉพาะหญิง)
```

| eGFR | ระยะ |
|---|---|
| ≥ 90 | Stage 1 |
| ≥ 60 | Stage 2 |
| ≥ 45 | Stage 3a |
| ≥ 30 | Stage 3b |
| ≥ 15 | Stage 4 |
| < 15 | Stage 5 (ESRD) |

- 🔴 **ครบ 6 ระยะ ห้ามรวมระยะเข้าด้วยกัน** — เคยโดนด่าเรื่องรวม Stage 4 กับ 5 (สกิล `medical-data-safety`)
- 🔴 **เขียนกำกับทั้งบนจอและในโค้ดว่าแสดงผลเท่านั้น** ห้ามเอาไปตัดสินขนาดยา · ตัวที่ใช้ปรับขนาดยาคือ CrCl ข้อ 1
- เป็นสูตรรุ่นไม่มีตัวแปรเชื้อชาติ · ใบผลของ HIS เขียนแค่ eGFR [CKD-EPI] ไม่บอกรุ่น ตัวเลขอาจต่างจาก HIS เล็กน้อย ไม่ใช่ตัวใดผิด
- 🔴 **ดูระยะจากค่าก่อนปัดเสมอ** ปัดตอนแสดงตัวเลขเท่านั้น — พี่กันเคาะ 6 ต.ค. 2569 *"ใช้แบบก่อนปัด ตามที่จอโชว์"*
  ตัวอย่างจริง ชาย อายุ 52 sCr 1.41 ได้ 59.9603 จอแสดง **60.0 คู่กับ Stage 3a** = ถูกต้อง ห้ามปัดเป็น 60.0 ก่อนแล้วได้ Stage 2
  เกิดเฉพาะค่าที่ตกในช่วง 0.05 ใต้ขอบ 90 60 45 30 15 · ไล่อายุ 40–85 กับ sCr 0.50–2.00 เจอ 35 จาก 13,892 คู่

# 5. BMI เกณฑ์ WHO Asia-Pacific — แสดงผลเท่านั้น

`BMI = น้ำหนัก kg / (ส่วนสูง m)²`

| BMI | ระดับ |
|---|---|
| < 18.5 | Underweight (ผอม) |
| < 23 | Normal Weight (ปกติ) |
| < 25 | Overweight (น้ำหนักเกิน) |
| < 30 | Obese I (อ้วนระดับ 1) |
| < 35 | Obese II (อ้วนระดับ 2) |
| ≥ 35 | Obese III (อ้วนระดับ 3) |

- 🔴 **ไม่ใช่เกณฑ์ WHO สากล** (สากลใช้ 25 เป็นน้ำหนักเกิน) · ต้นฉบับมีหัวข้อเขียนว่า "WHO Global" แต่ตัวเลขข้างในเป็น Asia-Pacific ยึดตัวเลข
- ชื่อระดับแสดงเป็นก้อนเดียว ห้ามตกบรรทัดกลางวลี

# 6. ค่าอ้างอิง sCr

| เพศ | ช่วงปกติ |
|---|---|
| ชาย | 0.7–1.2 mg/dL |
| หญิง | 0.5–1.0 mg/dL |

- เทียบในหน่วย mg/dL หลังแปลง · ต่ำกว่าตัวล่าง = Low · สูงกว่าตัวบน = High · เท่าขอบ = ปกติ
- **ยังไม่เลือกเพศ = ยังไม่บอกว่าสูงหรือต่ำ** (ต้นฉบับใช้ช่วงของผู้หญิงเตือนไปก่อน · กล่อง CrCl เลือกไม่เตือนจนกว่าเลือกเพศ)

**วิธีบอกสูงต่ำที่พี่กันคิดเอง** (5 ต.ค. 2569)
> *"เราว่า 7-2 ต้องเขียนใหม่เลย มั้ย เช่นเอา ref มาเเล้วเขียน low high งี้"*
> *"1.6 : ชาย 0.7–1.2 High หญิง 0.5–1.0 mg/dL · 0.6 : ชาย Low 0.7–1.2 หญิง 0.5–1.0 mg/dL"*
> *"high low เอาสีตามเว็บ hcv หน่อย"* · *"เอาลูกศรขึ้นลง ใส่ใน 1.6 แต่ 1.6 ไม่ขยับนะ"*

- ใต้ช่องเขียนช่วงของทั้งสองเพศ · คำว่า **High วางหลังเลขตัวบน · Low วางหน้าเลขตัวล่าง** ของเพศที่เลือก
- สีตามป้าย H L ของเว็บ HCV — High แดง `#dc2626` · Low ส้ม `#ea580c`
- ในช่อง sCr มีบั้งคู่ชี้ขึ้นหรือลงต่อท้ายตัวเลข **ตัวเลขต้องไม่ขยับ** (บั้งวางทับเป็นชั้นบน ไม่แทรกในช่อง)

# 7. คำหมายเหตุที่เจ้าของงานเคาะแล้ว — ยกไปใช้ทั้งประโยค ห้ามแต่งเพิ่ม

| สถานการณ์ | คำบนจอ |
|---|---|
| บอกน้ำหนักที่ใช้ | `ใช้ Ideal BW 58.6 kg` · `ใช้ Actual BW 45.0 kg` · `ใช้ Adjusted BW 72.1 kg` |
| ผอม (กรณีที่ 2) | `Underweight: มวลกล้ามเนื้อน้อย CrCl อาจสูงเกินจริง` |
| เตี้ย (กรณีที่ 1) | `ส่วนสูง < 152 cm: อาจหลังค่อม CrCl อาจต่ำเกินจริง` |
| ไม่กรอกส่วนสูง (กรณีที่ 5) | `กรุณากรอกส่วนสูง` |

| อายุนอกช่วง (ใต้ช่องอายุ) | `เกินช่วงอายุที่สูตรรองรับ 18–92 ปี` · `ต่ำกว่าช่วงอายุที่สูตรรองรับ 18–92 ปี` |
| หมายเหตุสูตรใต้ตารางน้ำหนัก | `IBW (Devine Formula) · Adjusted BW: IBW + 0.4 x (BW - IBW)` |
| ชี้ที่คำว่า Devine Formula | `Devine Formula (kg)` · `ชาย: IBW = 50 + 2.3 x (Height (in) - 60)` · `หญิง: IBW = 45.5 + 2.3 x (Height (in) - 60)` · `Height (in) = Height (cm) / 2.54` |

**แบบแผนที่ใช้กับคำใหม่ได้**
- หมายเหตุขึ้นต้นด้วย **กรณี ตามด้วยทวิภาค แล้วผลกระทบ** — `กรณี: CrCl อาจ...`
- **ชื่อสูตรเขียนเต็มและอยู่ในวงเล็บ** — *"มันควรเขียนว่า Devine Formula เพราะถ้าเเค่ Devine ใครมันจะรู้"* · *"วงเล้บไหมนะ เพราะตามจุดอื่น ถ้าสูตร มันจะวงเล็บ"*
- ใช้คำว่า **ส่วนสูง** และเครื่องหมาย **<** แทนคำว่า ต่ำกว่า — *"ใช่คำว่า ส่วนสูง"* · *"ต่ำ่วาา เป็น <"*
- สั้นที่สุดที่ยังครบความ — *"กรุณากรอกส่วนสูง เอาเเค่นี้"* · *"เอา อาจหลังค่อม"*

# 8. 🔴 เกณฑ์ปรับขนาดยา — ห้ามเอาเลขของยาตัวหนึ่งไปใช้กับยาอื่น

- **CrCl < 30 mL/min ในต้นฉบับ คือเกณฑ์ของยาวัณโรค** (ให้ยาบางตัว 3 ครั้งต่อสัปดาห์) ไม่ใช่เกณฑ์กลางของทุกยา
- ยาแต่ละตัวมีจุดตัดของตัวเอง **ต้องมีแหล่งอ้างอิงของยานั้น หรือพี่กันยืนยัน** ก่อนใส่ (สกิล `medical-data-safety`)
- เว็บไหนใช้เลข 30 ทำสีตัวเลข CrCl (เช่นกล่อง CrCl บน Chrome) **ต้องเขียนกำกับว่าเป็นแค่สีบอกระดับ** ไม่ใช่คำแนะนำปรับยา
- กล่อง CrCl ตัดสินสีจากเลขที่แสดง (ทศนิยม 1) ไม่ใช่ค่าก่อนปัด — 29.96 แสดง 30.0 ได้สีของ 30 ขึ้นไป
- ต้องการสูตรนอกต้นฉบับ (เด็ก · ฟอกไต · สูตรอื่น) = ไม่มีในสกิลนี้ **ห้ามคิดเอง** ถามพี่กันพร้อมแหล่งอ้างอิง

# โค้ดอ้างอิง — เรียบเรียงจากกล่อง CrCl ซึ่งเทียบกับต้นฉบับแล้ว

`pickWeight` แยกออกมาจาก `compute(st)` ให้อ่านง่าย · ทดสอบแล้วว่าเลือกน้ำหนักตรงกับ `compute(st)` ทุกกรณี (6 ต.ค. 2569)

```js
// CrCl Cockcroft-Gault · ตัวนี้ใช้ปรับขนาดยา · ไม่ปัดค่า sCr · ผู้หญิงคูณ 0.85
function calcCrCl(bw, age, scr, sex) {
  const v = ((140 - age) * bw) / (72 * scr);
  return sex === 'female' ? v * 0.85 : v;
}
// w kg · h cm · scr mg/dL (แปลงหน่วยก่อนเรียก) · คืนน้ำหนักที่เลือกกับเหตุผล
function pickWeight(w, h, sex) {
  if (!Number.isFinite(h)) return { pick: 'A', kind: 'noheight' };
  const over60 = Math.max(0, h / 2.54 - 60);
  const ibw = sex === 'male' ? 50 + 2.3 * over60 : 45.5 + 2.3 * over60;
  const adj = ibw + 0.4 * (w - ibw);
  if (h < 152) return { pick: 'A', kind: 'short', ibw: null, adj: null };
  if (w < ibw) return { pick: 'A', kind: 'under', ibw, adj };
  if (w > ibw * 1.2) return { pick: 'J', kind: 'obese', ibw, adj };
  return { pick: 'I', kind: 'normal', ibw, adj };
}
// eGFR CKD-EPI 2021 · แสดงผลเท่านั้น ห้ามเอาไปปรับขนาดยา
function calcEGFR(scr, age, sex) {
  const k = sex === 'female' ? 0.7 : 0.9;
  const a = sex === 'female' ? -0.241 : -0.302;
  const r = scr / k;
  return 142 * Math.pow(Math.min(r, 1), a) * Math.pow(Math.max(r, 1), -1.2)
    * Math.pow(0.9938, age) * (sex === 'female' ? 1.012 : 1);
}
// ระยะ CKD ครบ 6 ระยะ ห้ามรวม · ส่งค่าก่อนปัดเข้ามาเสมอ (ข้อ 4)
function ckdStage(v) {
  if (v >= 90) return 'Stage 1';
  if (v >= 60) return 'Stage 2';
  if (v >= 45) return 'Stage 3a';
  if (v >= 30) return 'Stage 3b';
  if (v >= 15) return 'Stage 4';
  return 'Stage 5 (ESRD)';
}
// BMI เกณฑ์ WHO Asia-Pacific · แสดงผลเท่านั้น
function bmiClass(b) {
  if (b < 18.5) return 'Underweight (ผอม)';
  if (b < 23) return 'Normal Weight (ปกติ)';
  if (b < 25) return 'Overweight (น้ำหนักเกิน)';
  if (b < 30) return 'Obese I (อ้วนระดับ 1)';
  if (b < 35) return 'Obese II (อ้วนระดับ 2)';
  return 'Obese III (อ้วนระดับ 3)';
}
```
