# สรุป session: ทำงาน Claude Code ข้ามเครื่อง (2 ก.ค. 2569)

> เป้าหมายใหญ่: **แก้โค้ดจากที่ไหนก็ได้** (มือถือ/คอม) โดยให้ Claude "ฉลาดเท่ากันทุกเครื่อง"
> หลักการ: อะไรที่อยู่ใน **repo** จะตาม Claude ไปทุกที่ (เพราะโคลนจาก GitHub) → เอาความรู้ไปเก็บใน repo

---

## Claude Code รันที่ไหนบ้าง (3 ที่)

| ที่ใช้ | รันที่ไหน | ไฟล์ที่ทำงาน | เก็บแชท |
|---|---|---|---|
| Terminal (CLI) ในคอม | เครื่องเรา | ไฟล์ในคอมตรง ๆ | ในเครื่อง (local) |
| เว็บ/มือถือ (claude.ai/code) | คลาวด์ | โคลนจาก GitHub | คลาวด์ |
| Claude Desktop (แอป) | เลือกได้ Local/Remote | Local=ไฟล์ในคอม / Remote=โคลน GitHub | ในเครื่อง (local) |

- แชท **ไม่ sync อัตโนมัติ** ระหว่าง 3 ที่
- CLAUDE.md + `.claude/` + ไฟล์ใน repo → **ตามไปทุกที่** (อยู่ใน repo)
- user memory (`~/.claude`) + ประวัติแชทเก่า → **ไม่ตามไป** (เก็บ local อย่างเดียว)

## ย้าย session ข้ามเครื่อง (พาบทสนทนาเดิมไปทำต่อ)

| ย้ายจาก → ไป | ใช้อะไร |
|---|---|
| คอม (Desktop app) ➡️ เว็บ/มือถือ | ปุ่ม **Continue in web** (กดในแอป Desktop) |
| เว็บ/มือถือ ➡️ คอม (Terminal) | คำสั่ง **`--teleport`** (พิมพ์ใน terminal) |

- 2 ท่านี้พา "บทสนทนาเดิม" ตามไปด้วย (ไม่ใช่เริ่มใหม่)
- จาก terminal ธรรมดา ดันขึ้นเว็บเองไม่ได้ (ต้องผ่าน teleport ทางเดียว)

## วิธีทำงานที่ตกลงกัน

### 1. บทเรียนสำคัญ + คำสั่งโปรเจกต์ → เก็บใน `CLAUDE.md`
กฎถาวร / สไตล์งาน / ข้อผิดพลาดที่เคยสอน / คำสั่งเฉพาะโปรเจกต์
→ เลือกเฉพาะเรื่องสำคัญ อย่าให้บวม (Claude อ่านไฟล์นี้ทุกครั้งที่เริ่มคุย)

### 2. สรุป session (เคส) → ไฟล์แยกใน `docs/session-notes/`
เขียนย่อ ๆ แล้ว push ขึ้น Git → ไม่โหลดอัตโนมัติ (CLAUDE.md ไม่อืด)
เวลาจะใช้: บอก Claude ว่า "ไปอ่าน `docs/session-notes/xxx`" → เปิดอ่านได้ทันที

### 3. ทำงานข้ามเครื่องผ่าน GitHub
สั่งจากมือถือ → Claude แก้บนคลาวด์ → push → กลับถึงคอมสั่ง `git pull` ลงเครื่อง
(คอมบ้านไม่ต้องเปิดค้างไว้)
