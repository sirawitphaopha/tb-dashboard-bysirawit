## 🧠 สาระที่คุยกัน (บริบทสำคัญสำหรับ session หน้า)
**workflow จริงของพี่กัน:** เตรียมเคส TB ก่อนวัน clinic → คัดว่าเคสไหนต้อง consult → เขียนโน้ตถึงหมอ → **ปริ้นเป็นกระดาษยื่นหมอ** (ระบบกระดาษ · เดิมทำใน Google Sheet แล้วปริ้น)

**หน้าที่แอป 3 อย่าง (พี่กันย้ำ "เนื้อหาเราเขียนเอง แอปไม่ต้องคิดแทน"):**
1. ที่กรอกข้อมูล 2. **ระบบเตือนให้มองหาง่าย ← หัวใจจริง** 3. ปริ้นเป็นใบ
- Google Sheet ทำข้อ 1+3 ได้แล้ว เหตุผลเดียวที่ต้องมีแอป = ข้อ 2 (เตือน)

**จุดเสียเวลาที่สุด:** (1) **สรุปเคส (ช่อง Detail)** ไทม์ไลน์ยาวไล่ค่าแลป — นานจนช่วงหลังพี่กันเลิกทำ (2) พิมพ์ค่าแลปมือ

**วิสัยทัศน์ AI 4 ชั้น (จบที่พี่กันเสมอ):** เตือนอัตโนมัติ(กฎ) → AI ส่องจุดบอด → AI ร่าง consult **ตามรสมือ** (few-shot จาก consult เก่าพี่กัน) → พี่กันเกลาจบ

**ฟีเจอร์เด่นที่คุย:**
- 📸 **OCR ค่าแลป** จากปริ้นสกรีน Himpro (ไม่ถ่ายกล้อง = คมชัด AI แม่นเกือบ 100%) → เด้งเข้าช่อง → พี่กันยืนยัน · โบนัส: auto คำนวณ CrCl (Cockcroft-Gault)
- 🔄 **Auto-timeline** = กรอกช่องแยกทุก visit → แอปต่อไทม์ไลน์เอง = **กรอกครั้งเดียว = สรุปในตัว** + กราฟ trend ค่าแลป → คำตอบของ "จะย่อระบบสรุปเคสยังไง"
- ✅ **ระบบติ๊กทำแล้ว** แทนขีดฆ่ากระดาษ
- 🔌 **เชื่อม Himpro** (ฝันไกล): Himpro = HIS ไทย VB6 ปี 2542 + **MySQL** · **ไม่มี API/key** (เก่าเกิน) ประตูเดียว=MySQL ตรง · ต้องมี "ตัวแปล" รันในวง รพ. + IT อนุญาต · ใช้ได้เฉพาะ WiFi รพ. → **OCR ชนะขาดตอนนี้** (ไม่พึ่งใคร ทำได้เลย) · ช่องกรอกค่าแลปช่องเดียวกัน เปลี่ยนแหล่งทีหลังได้

**จุดตัดสินใจใหญ่สุด (ยังไม่สรุป · รอตอนทำจริง):** ช่องกรอกสูตรยา = พิมพ์อิสระ (เร็ว แต่แอปเตือนไม่ได้) vs กรอกแยกช่อง (แอปฉลาด คำนวณ mkd ได้ แต่ช้า) · พี่กันบอก "เดี๋ยวสั่งตอนทำจริง จะแก้ไปมาจนเข้ามือ"

**PDPA:** พี่กันบอก "ใช้วงปิด ไม่ต้องแคร์มาก" (ข้อมูลไม่ออนไลน์สาธารณะ) → จดไว้ทบทวนตอนเปิดจริง
